# Mi Horario: Cuenta Atrás

Widget para Android que muestra cuánto queda de la clase actual o cuánto falta para la siguiente. El color cambia según se acerca la hora.

- Puedes importar el horario desde Excel o CSV, o pegando lo que devuelve una IA a partir de una foto de tu horario.
- No recoge datos: todo se queda en el teléfono.
